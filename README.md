# warehouse-assembly

Веб-система сборки заказов на складе БАД: приёмка живого спроса с маркетплейсов и сборка заказов сотрудниками по сканированию.

Унифицированное монорепо из нескольких приложений под разные кабинеты маркетплейсов, с общим ядром. Используется на складе в ежедневной работе.

## Приложения (`apps/`)

- **sborka** — основное приложение сборки: вход сотрудника, сканирование товара/ячейки, отбор заказов, моментальная сборка, возвраты, озвучка, индикатор раскладки.
- **WB** — кабинет Wildberries: поставки, ячейки, печать этикеток, дозатор банок.
- **OZ** — кабинет Ozon: «ожидают отгрузки», консолидация поставок, печать.
- **YM** — кабинет Яндекс.Маркет: FBS-сборка и назначение.
- **shared** — общий код (помощники БД, QR/флаеры, утилиты).

## Стек

- Backend: Node.js / Express (ESM, `server.mjs` в каждом приложении), PostgreSQL
- Frontend: React + Vite
- Печать этикеток: термопринтер (TSPL)
- `migrations/` — SQL-миграции, `scripts/` — утилиты обслуживания и аудита

## Запуск

Каждое приложение самостоятельно:

```bash
cd apps/sborka
npm install
cp ../../.env.example .env     # заполнить доступы к БД и кабинетам
node server.mjs                # бэкенд
npx vite                       # фронтенд (dev)
```

Доступы к БД и API маркетплейсов, а также `INTERNAL_PROXY_TOKEN` для меж-кабинетного прокси задаются через переменные окружения — см. `.env.example`.
